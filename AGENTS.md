# home-w42-eu

The vision, principles and architecture for the home platform. See [README.md](README.md) for the reading order.

- This repo holds design documents only. Code lives in the repos listed in the README.
- Start from [docs/use-cases.md](docs/use-cases.md): every design change should serve a use case there, and say which.
- [docs/principles.md](docs/principles.md) is binding on all of them. Check a design or code change against it.
- Keep [docs/fit-and-roadmap.md](docs/fit-and-roadmap.md) current when a stage is done or a repo changes role.
- New device, adapter or loop ideas go to `../home-w42-eu-ideas` (one file per idea), not here. An idea moves into the architecture only when it changes the design.
- Mark the status and date on every document. Say what was proved on hardware and what is design only.
- Write in plain, short English, like the other documents.
